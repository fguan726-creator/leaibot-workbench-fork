# 布局与栅格（PC 端 · 乐享 AI 工作台）

页面骨架、栅格、各类页型的标准结构。用于保证当前乐享 AI 工作台在不同设备、不同需求页面生成时保持一致。
尺寸值复用 `design-tokens.md` 第 7~8 节，这里不再重复定义，只规定"怎么用"。

中间业务内容槽的范围、页型选择、组件组合和状态完整性以 `content-slot-design-contract.md` 为权威入口；本文件补充栅格和壳层关系。

## 1. 适配范围与断点

桌面优先，以 `1280px` 为 PC 壳层设计基线。内容槽内部必须按实际容器宽度响应，完整等级与页型降级以 `responsive-layout-contract.md` 为权威入口。

| 范围 | 行为 |
|------|------|
| viewport `<=1320px` | 壳层允许自动收起侧栏为 `58px` |
| viewport `>=1480px` | 只恢复系统自动收起的侧栏 |
| content `>=1040px` | 内容槽可使用四列筛选和宽页型布局 |
| content `720–1039px` | 内容槽主要降为两列 |
| content `<720px` | 内容槽主要降为单列；页面根仍不得横向溢出 |

现行决策：数据密集型内容槽默认 `width:100%; max-width:none; min-width:0`。`--content-max:1440px` 只作为确有阅读宽度需求的可选上限，不用于普通运营看板、列表、表格或动态报告。

### 1.1 壳层缩屏顺序

工作台在缩小浏览器或打开右侧 Agent 时，必须保持统一裁切顺序：

1. 中间内容槽按容器阈值先降级。
2. 再按 `1320/1480px` viewport 滞回规则处理左侧导航。
3. 最后才约束右侧 Agent 区。

因此，页面内部布局不得使用刚性最小宽度抢先裁切内容槽。两栏/三栏页面的主内容列使用 `minmax(0,1fr)`；所有 grid/flex 直接子项都要能 `min-width:0`；辅助列可用 `clamp(220px, 26%, 300px)` 这类弹性宽度；当中间槽不足时，页面内部先切到单列，而不是让 `.page-content` 或页面根容器出现提前横向裁切。

## 2. 应用框架 App Shell（全局统一）

所有页面共用这一层外壳，内容区才是各页差异所在。

```
┌──────────────────────────────────────────────────────┐
│  顶栏 Header  56px                                       │
│  [面包屑]                         [主题] [AI助手]         │
├────────┬─────────────────────────────────────────────┤
│ 侧栏    │  内容区 Content                                │
│ 168px  │  ┌─ 页头：标题 + 描述 + 主操作 ──────────────┐  │
│ 浅色    │  │                                          │  │
│ (可收起 │  └──────────────────────────────────────────┘  │
│  到58) │  ┌─ 页面主体（卡片/表格/表单/图表）────────────┐  │
│        │  │                                          │  │
│        │  └──────────────────────────────────────────┘  │
└────────┴─────────────────────────────────────────────┘
```

- 侧栏：浅色(#FFFFFF) + 右侧 #DEE0E3 分隔线，展开 168px，收起到 58px。
- 顶栏：吸顶(`--z-sticky`)，含面包屑、静态页签与全局功能。当前 0825 Vue 联想门户工作台默认隐藏全局搜索框。
- 内容区：背景 `--color-bg`，内边距 `--content-padding`(24px)。
- 右侧 AI 助手：打开时默认 380px，独立滚动；关闭时宽度为 0，顶栏显示 AI 助手开关；支持拖拽扩宽到约 492px。
- AI 结果报告：不属于左侧导航层级，也不生成顶栏下方的第二排页签。当前会话存在已打开结果时，在 Topbar 静态页签右侧显示单一 `AI 结果报告`选择器；激活结果后，完整报告、链接或 HTML 预览直接渲染在中间内容槽。无结果时选择器隐藏且不占高度。

## 3. 栅格 Grid

内容区主体采用 **12 列栅格**，列间距(gutter) `--space-6`(24px)。常用分栏：

- 单列：表单页、详情页（配 `--container-narrow` 居中）
- 主从两栏：左主内容 + 右侧信息栏（如 8:4 或 主区 + 320px 固定侧栏）
- 卡片墙：`repeat(auto-fill, minmax(280px, 1fr))` 自适应换行（仪表盘指标卡）

| 变量 | 值 | 用途 |
|------|-----|------|
| `--container-narrow` | `720px` | 表单/阅读型页面居中宽度 |
| `--grid-columns` | `12` | 栅格列数 |
| `--grid-gutter` | `24px`(=`--space-6`) | 列间距 |

## 4. 页型模板（核心：把常见页面结构定死）

当前项目页面优先归入下面几类。每类给出标准结构，做 HTML 预览时直接套对应模板。

### 4.1 仪表盘 / 概览页 Dashboard
```
页头：标题 + 时间范围筛选
─ 指标卡行：4 个 Stat Card 并排（auto-fill 自适应）
─ 图表区：2 列（左大图 + 右小图）或整宽趋势图
─ 列表区：近期任务 / 告警表格（普通业务默认 48px；明确高密度单行时可用 40px）
```

适用当前项目：运营总览、Query 分析、质量分析、流量分析、GMV 分析、GEO 各类看板、线索看板。

### 4.2 列表 / 表格页 List（最高频）
```

适用当前项目：职场员工审核、留言工单、线索池、手工上传知识、员工管理。
页头：标题 + 右侧主操作（如"新建模型"）
─ 筛选栏：搜索框 + 若干筛选器 + 重置（一行，可折叠"高级筛选"）
─ 批量操作条：选中行后浮现（仅当启用批量选择）
─ 表格：普通业务默认 48px；明确高密度单行任务/配置表可用 40px + 操作列保持最右可达
─ 分页器：底部右对齐
```

### 4.3 详情页 Detail
```
页头：面包屑返回 + 对象名 + 状态标签 + 右侧操作
─ Tabs：概览 / 配置 / 日志 / 版本 …
─ Tab 内容：主从两栏 或 多个分组卡片
```

### 4.4 表单 / 配置页 Form
```
单列居中（--container-narrow 720px）
─ 分组卡片：每组一个 Card，组内字段标签在上
─ 多字段 → 右侧抽屉；简单确认 → 居中弹窗
─ 底部操作区：右对齐"取消 / 保存"，长表单可吸底
─ 复杂多步 → 用 Steps 分步向导
```

### 4.5 设置页 Settings
```
左侧二级导航（账户/安全/密钥/成员…）+ 右侧对应设置表单
─ 每节一个卡片，标题 + 说明 + 控件 + 独立"保存"
```

### 4.6 空白 / 引导页
```
内容区居中：图标 + 说明 + 主操作（见组件 Empty）
```

## 5. 间距节奏（统一留白层级）

让信息层级靠间距就能读出来，遵循"越相关越靠近"。

| 场景 | 间距 |
|------|------|
| PageHeader 到第一个业务区块 | `--space-4`(16px) |
| 其余顶层业务区块之间（区与区） | `--space-6`(24px) |
| 同一区块内模块 / 普通卡片网格 | `--space-4`(16px) |
| 普通卡片内边距 | `--space-5`(20px) |
| 卡片内分组之间 | `--space-4`(16px) |
| 表单项之间 | `--space-4`(16px) |
| 标签与控件之间 | `--space-2`(8px) |
| 行内元素（图标与文字、标签间） | `--space-2`(8px) |

KPI 组合使用统一页头节奏：页头到 KPI `16px`、KPI 卡间 `14px`、KPI 到下一模块 `16px`。页头到首区块不再区分看板、Skill 创建、表单或列表页；实现时不得同时叠加 PageHeader margin 和父容器 gap。

## 6. 页头规范 Page Header（每页统一）

所有页面顶部的标题区结构一致：
- 左：（详情页可带返回箭头/面包屑）页面标题 `--text-xl` + 可选一句描述 `--text-secondary`；标题前不强制装饰方块，只有稳定语义图标才可出现
- 右：按任务需要放主操作按钮（primary），次操作放其左侧；无页面级操作时可以省略整组
- 与下方主体间距 `--space-6`，下可加 `--color-border` 分隔线（可选）
- 窄内容槽下标题区可换为上下两行；操作顺序和可点击区域保持稳定

## 自检（布局层面）

- [ ] 用了统一的 App Shell（侧栏 + 顶栏 + 内容区）
- [ ] 页面归入了某个页型模板，结构与同类页一致
- [ ] 数据密集页面流式撑满；只有阅读/表单型内容使用有理由的受控最大宽度
- [ ] 间距按第 5 节节奏，层级清晰
- [ ] 每页都有页面标题；描述和页面级操作按任务需要出现
