# 内容槽响应式布局合同

本文件给出门户工作台中间内容槽可直接实现和验收的响应式阈值。所有阈值默认指页面根容器的**实际可用内宽**，不是浏览器 viewport。壳层的侧栏和 Agent 仍使用 viewport 与运行时状态控制。

## 1. 响应式测量模型

实现和验收同时记录四个值：

```text
viewportWidth
sidebarWidth = 168 / 58
agentWidth = 0 / 380 / dragWidth（最大约 492）
contentInnerWidth = 页面 padding 内层的响应式布局容器 getBoundingClientRect().width
```

页面布局只根据 `contentInnerWidth` 选择列数。响应式容器应位于页面 `20px 24px` padding 内部，本身不再带水平 padding，使 `getBoundingClientRect().width` 与 Container Query 的 content box 一致。不得从 `viewportWidth - 固定常数` 猜测页面宽度，也不得因为 Agent 打开而写另一套页面结构。

`1040/720px` 是两个基础栅格密度断点，不是页面锁宽值：页面始终 `width:100%` 流式占满内容槽，`repeat(4,minmax(0,1fr))` 中的每列会随容器继续伸缩。普通筛选默认以四列作为大屏密度上限；图表、表格、分栏和专项页型继续按第 5 节利用更宽空间。

壳层缩放顺序固定：

1. 内容槽页面按容器宽度降列、换行或隐藏次要信息。
2. viewport 达到壳层阈值后，左侧导航自动收起。
3. 导航收起后仍不足，才约束右侧 Agent；内容槽不得继续被中心裁切。

页面根、直接 grid/flex 子项和可滚动容器使用 `min-width:0`；主列使用 `minmax(0,1fr)`。页面根节点的 `scrollWidth - clientWidth` 必须为 `0`。

## 2. 壳层 viewport 规则

以下值来自当前 0825 Vue 运行时，不得改成页面局部断点：

| 条件 | 壳层行为 |
|---|---|
| viewport `<=1320px` | 允许系统自动把侧栏从 `168px` 收到 `58px` |
| viewport `>=1480px` | 只把“系统自动收起”的侧栏恢复到 `168px`；手动收起保持 |
| viewport `1280px` | 当前桌面最低验收基线；初始加载也执行自动收起判断 |
| Agent 关闭 | 宽度 `0`，不占内容空间 |
| Agent 默认打开 | 宽度 `380px` |
| Agent 拖拽 | `380px` 至约 `492px`；达到最大且 viewport 较窄时可触发侧栏自动收起 |

`1320/1480` 是带滞回的壳层阈值，避免窗口在临界点反复开合。内容槽不能复制这两个数作为卡片或筛选断点。

低于 `1280px` 时当前项目可以保留壳层全局最小宽度滚动，但单个业务页面仍必须通过容器测试，不得产生自己的横向溢出。

## 3. 内容槽容器宽度等级

| 等级 | `contentInnerWidth` | 默认能力 |
|---|---:|---|
| C-XL | `>=1200px` | 4 列筛选、4 KPI、2–3 个分析列、完整工具栏、分栏设置 |
| C-L | `1040–1199px` | 4 列筛选、4 KPI 或 2+2、双列分析、完整工具栏 |
| C-M | `720–1039px` | 2 列筛选、2 KPI、单/双列分析、工具栏允许换行 |
| C-S | `480–719px` | 1 列筛选、1 KPI、单列内容、页头与操作分行 |
| C-XS | `<480px` | 单列、次操作收纳、全宽主操作；仅用于组件级压力测试 |

阈值使用闭区间约定：恰好 `1040px` 进入 4 列筛选，恰好 `720px` 进入 2 列，恰好 `480px` 进入 C-S。为了避免边界抖动，JS 行为切换如确有必要，应使用 8–16px 滞回；纯 CSS container query 不需要额外滞回。

基础规则的 CSS 上界写为 `1039/719px`，分别对应规范中的 `1040/720px`。`920/620px` 不再作为通用内容槽断点；表格 `min-width:920px`、阅读容器 `max-width:720px`、弹窗宽度或经登记的组件局部断点等同数值可按原语义保留，禁止全局搜索替换。

## 4. 字段与控件最小可读宽度

这些是内容宽度，不含相邻网格 gap；低于建议值时应跨列、换行或降列，不能缩小字体和点击区域。

| 字段 / 控件 | 推荐最小宽度 | 规则 |
|---|---:|---|
| 短枚举 Select | `160px` | 长选项显示省略与完整 Tooltip |
| 普通文本 / ID 输入 | `200px` | 业务搜索优先 `240px` |
| 全文搜索 | `240px` | C-S 下占满一行 |
| 单日期 | `180px` | 多个日期必须显示可见标签 |
| 日期时间 | `220px` | 不拆成多个无法识别的小框 |
| 日期范围 | `280px` | 在 4 列网格中允许跨 2 列 |
| 组织 / 级联选择 | `240px` | 层级深时跨 2 列或使用 Drawer |
| 数字区间 | `220px` | 起止值保持成组，不分散到两行 |
| 查询 / 重置动作组 | `160px` | 保持按钮同高、顺序稳定 |
| 表格操作列 | `96px` | 多于 3 个操作时收进“更多” |
| 分栏设置左栏 | `220–300px` | 推荐 `clamp(220px,26%,300px)` |
| 表单正文列 | `320px` | 两列不足时转单列 |

## 5. 七类页型降级矩阵

### 5.1 标准列表与长筛选列表

| 容器等级 | 筛选 | 工具栏 | 表格 |
|---|---|---|---|
| C-XL / C-L | 4 列；日期范围等可跨 2 列 | 单行，统计左、页面动作右 | 容器内横向滚动，操作列右固定 |
| C-M | 2 列；常用条件优先 | 允许两行，批量状态独占一行 | 不转卡片，不隐藏关键业务列 |
| C-S / C-XS | 1 列；长筛选默认收起次要条件 | 主操作可全宽，次操作进更多 | 仍为表格语义；横向滚动只在表格容器内 |

常用条件 `<=3` 选标准列表；`>=4` 或需要高级筛选选长筛选列表。列数变化不改变该页型判断。

### 5.2 数据看板

| 模块 | 4 列 | 2 列 | 1 列 |
|---|---:|---:|---:|
| KPI | `>=1040px` | `720–1039px` | `<720px` |
| 双图表 | — | `>=880px` | `<880px` |
| 三分析列 | `>=1280px` 可 3 列 | `880–1279px` 2 列 | `<880px` 1 列 |
| 复杂矩阵 / 排行 | 保持表头与对象列 | 容器内滚动或减少辅助列 | 不缩成不可读微型图 |

图表在容器宽度变化、Agent 开关、tab 激活、筛选展开和字体加载后调用 `resize()`。空、错误和无权限状态必须与图表容器等高，避免布局跳动。

### 5.3 业务表单

- `>=900px`：可使用两列字段；跨列说明、日期范围、富文本和权限范围占满一行。
- `<900px`：单列字段；字段顺序按任务流程，不按原左右列交错。
- 阅读/表单型正文可使用 `max-width:720px`，但外层页面、告警和底部操作仍占满可用宽度。
- `<720px`：底部操作允许换行；主操作保持最后和最突出，不反转取消/保存顺序。
- StickyActions 必须为正文预留等高底部空间；错误后焦点移动到首个错误。

### 5.4 任务 / 导入

- 参数卡：`>=1040px` 3–4 列，`720–1039px` 2 列，`<720px` 1 列。
- 上传区、进度、结果摘要和失败明细始终整行，不与参数字段挤成窄列。
- C-S 下状态时间线可改为纵向；阶段、成功/失败数量、重试与下载不能隐藏。
- 任务表格按列表页规则滚动，不用普通空表代替排队、运行、部分成功和失败状态。

### 5.5 分栏设置

- `>=960px`：保持 `clamp(220px,26%,300px) minmax(0,1fr)` 双栏。
- `720–959px`：左栏压到 `220px`；右侧复杂卡片降列。
- `<720px`：左栏变成顶部对象 Select、横向 tabs 或可展开列表；右侧工作区全宽。
- 切换布局前处理未保存状态；布局变化不能清空当前对象、焦点或滚动上下文。
- 权限管理属于已封板的 Agent Domain 专项分栏：当前桌面交付从 `1280px` 起保持左/右两列，权限 rail 与 Skill 创建左栏共用 `220–300px` 宽度合同，列间距 `16px`，不得因页面局部媒体查询提前改成上下结构。

### 5.6 配置列表

- 表格模式按列表页规则。
- 卡片模式：`>=1120px` 3 列，`720–1119px` 2 列，`<720px` 1 列。
- 状态、版本和主操作不得因降列消失；卡片正文可省略，详情由 Drawer/详情页承接。

### 5.7 专项变体

- 详情/审核：`>=960px` 可主从双栏，低于该值转单列；审批操作保持可见。
- 多步流程：步骤导航可横向滚动或简化为“当前步骤/总步数”，不能隐藏流程位置。
- AI 动态报告：目录栏 `>=960px` 可并列，低于该值移到正文上方或抽屉；正文宽度保持当前内容槽层级。
- 门户首页：能力卡 `>=1040px` 4 列，`720–1039px` 2 列，`<720px` 1 列。

## 6. 实现技术选择

优先级如下：

1. 页面根设置 `container-type:inline-size`，使用 `@container` 控制页面内部列数。
2. Shell 的侧栏自动收起、Agent 面板和全局最小宽度继续使用 `@media`、Pinia 和现有 composable。
3. 图表、canvas、虚拟表格等必须知道像素尺寸的组件使用 `ResizeObserver`，只负责测量/重绘，不重复维护 CSS 可表达的列数。
4. 旧 wrapper 暂时无法使用 container query 时，可用一个页面级 `ResizeObserver` 写入 `data-size="xl|l|m|s|xs"`；初始 mount 和每次 resize 使用同一函数，并在卸载时断开 observer。

推荐实现：

```css
.content-page-inner { container-type: inline-size; min-width: 0; }
.filter-grid { display:grid; grid-template-columns:repeat(4,minmax(0,1fr)); gap:16px; }
@container (max-width:1039px) { .filter-grid { grid-template-columns:repeat(2,minmax(0,1fr)); } }
@container (max-width:719px) { .filter-grid { grid-template-columns:minmax(0,1fr); } }
```

不要在 page-scoped CSS 中新增 `@media (max-width:1320px)` 来模拟侧栏状态，也不要通过 `window.innerWidth` 决定四列/两列。

静态页型模板也必须使用本合同的基础与专项断点，不得保留 `920/620px` 作为一套平行的通用模板规则。

## 7. Agent 开关与测试组合

每个新页型至少测试以下组合，并记录实际 `contentInnerWidth`：

| viewport | 侧栏预期 | Agent | 目的 |
|---:|---|---:|---|
| `1280` | 自动收起 `58` | `0` | 最低桌面基线、宽内容 |
| `1280` | 自动收起 `58` | `380` | 默认窄内容槽 |
| `1280` | 自动收起 `58` | 最大约 `492` | 极限挤压、Agent 优先级 |
| `1320` | 收起边界 | `380` | 自动收起阈值 |
| `1479` | 保持收起 | `380` | 滞回区间 |
| `1480` | 非手动状态可展开 | `380` | 自动展开阈值 |
| `1600` | 展开 `168` | `0 / 380 / 最大` | 常规办公屏三状态 |
| `1920` | 展开 `168` | `0 / 380 / 最大` | 宽屏、最大内容密度 |

另用容器测试夹具直接验证 `479/480/719/720/899/900/959/960/1039/1040/1119/1120/1199/1200/1279/1280px`，确保边界两侧各执行一次。

## 8. 量化验收

每次交付记录：

- `viewportWidth / sidebarWidth / agentWidth / contentInnerWidth`。
- 页面根 `scrollWidth - clientWidth = 0`。
- 表格外层页面无横向滚动；表格容器在必要时 `scrollWidth > clientWidth`，操作列仍可达。
- 所有直接 grid/flex 子项 `min-width:0`；长中文、英文 ID、日期范围和按钮组不重叠。
- 筛选列数、KPI 列数、表单列数、分栏模式符合本矩阵。
- Agent 打开/关闭后焦点不丢失，筛选值、表格选择、表单输入和滚动位置不被重置。
- 图表尺寸在布局稳定后与容器一致，控制台无 resize loop、error 或 warning。
- 键盘顺序与视觉顺序一致；Drawer/Modal 关闭后焦点返回触发源。
- `prefers-reduced-motion` 下非必要位移/打字动效可减弱或关闭，不影响状态理解。

无法测量的静态设计稿至少标注目标容器等级和预期列数；不得只写“响应式适配”。
