# 项目专项模块归属与封板边界

本文件定义当前 0825 项目专项模块的权威归属。它不创建新的通用组件白名单，也不授权新页面复制封板模块。普通控件外观仍继承 `design-tokens.md` 与 `components.md`。

| 专项模块 | 所属层 | 权威合同 | 可配项 | 锁定项 | 退出/演进路径 |
|---|---|---|---|---|---|
| 右侧 Agent、Composer、消息与队列 | 工作台壳层 | `workbench-interactions.md` | 会话数据、建议问题文案、已登记结构化结果 | 关闭/打开/拖宽行为、回答气泡、授权边界、Composer 几何与焦点 | 只有明确的新 Agent 需求才能修改；不得由内容槽页面反向覆盖 |
| 账号工作区 Popover | 工作台壳层 | `workbench-interactions.md` + 当前 Vue 源码 | 用户名、角色、可见入口 | 入口归属、层级、键盘/焦点返回、权限行为 | 提取为共享壳层组件后更新源码映射，不迁入内容槽组件序列 |
| 静态页签与 AI 结果选择器 | 工作台壳层 | `workbench-interactions.md` | 页签标题、当前会话结果 | Topbar 单一选择器、关闭语义、结果归属与上限 | 产品确认改变壳层信息架构后才允许调整 |
| Skill Hub / 技能包管理 | Agent Domain 封板模块 | 当前 Vue 源码 + `page-spec-coverage-matrix.md` | 业务列、标签、审批数据、权限可见性 | 生命周期状态、危险操作确认、语义 icon、完整反馈状态 | 稳定跨两个业务域后，将真正通用的子组件登记到 `components.md` F 节 |
| Skill 创建 / 权限管理 | Agent Domain 专项流程 | `workbench-interactions.md` + 当前 Vue 源码 | 字段、步骤内容、权限数据 | 流程状态机、固定底部操作、权限与失败恢复 | 需求确认后按 V2/E3/E4 更新，不复制为普通 T4/T6 页面默认结构 |
| 本地预览入口 | 交付辅助页 | `page-templates.md` | 说明文案、合法入口 | 不承载业务、不作为生产页面、不进入组件复用序列 | 目标环境不需要辅助入口时可移除 |

治理规则：

1. `components.md` A–D 是通用组件合同；E 只保留专项索引，F 只登记真实 Domain 复用模式。
2. 专项模块可以使用 Common 组件，但不能把自己的页面结构升级为 Common 默认值。
3. 新增专项模块必须记录所属层、源码、可配项、锁定项、全状态、响应式、确认结论和退出路径。
4. 删除或解封模块时同步更新本文件、页面矩阵、源码映射和验收证据。
