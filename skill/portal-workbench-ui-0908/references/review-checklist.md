## 4. 组件

- [ ] 按钮层级清晰，一个页面通常只有一个主按钮。
- [ ] 按钮、图标按钮、Tab、筛选 pill 高度稳定，文字不变形、不挤压、不意外换行。
- [ ] 按钮 / chip / 时间范围 pill 同组间距一致：图文 6px，同组 8px，横向内边距 12px；不用临时空格或随意 margin 修正位置。
- [ ] 表单标签在上，错误提示清晰。
- [ ] 表格有加载、空、错误状态。
- [ ] 状态标签同状态全站同色。
- [ ] 表格状态标签按内容自适应宽度，副文本使用专用 class；不存在 `td span` 等宽泛选择器把标签拉满整列或叠加副文本 margin。
- [ ] 危险操作有二次确认。
- [ ] 历史会话删除等高影响对话操作有行内二次确认或撤销入口，不能一键直接删除。
- [ ] Toast、Alert、Modal、Drawer 符合组件规范。
- [ ] 图表卡与表格卡同排时，内容区自适应且不空旷；图表已在布局变化后重新计算尺寸。
- [ ] 图表颜色使用单色阶或协调中低饱和色板，类别辨识度足够，同一语义跨图表颜色一致，强红只用于真实警示状态。
- [ ] 全站中间数据展示区的页面顶部 KPI / 主要数据卡片使用基于主色推导的蓝、青、靛、紫四种极浅辅助渐变循环，有色辅助色 alpha 低于 10%（推荐 2.5%-8%），白色收尾可为 100%，颜色有很轻的信息感但不明显抢眼；下方链路步骤 / 拆解项 / 二级统计块 / 图表容器 / 表格容器 / 筛选区 / 待接口占位块保持白底；未使用普通分类浅红、语义 wash、重复标签圆点、左侧色条或顶部色条。
- [ ] 本次样式调整已覆盖所有相关业务模块，不只覆盖“乐享运营”或某一个示例页面。
- [ ] Tabs 选中态只使用文字色 + 下划线，不使用整块背景高亮；Tabs 和筛选区有明确间距，不贴边、不重叠、不靠临时内联样式撑开。
- [ ] Tabs 点击后能切换 active 状态和内容面板，不存在“只显示 tab 样式但点击无反应”的静态 tab。
- [ ] Tabs 的点击逻辑切换标准 `.active` class，并清理冲突内联样式；不是仅修改 `style.color` 或下边框颜色。
- [ ] 描边线框型模块 / chip / 次按钮在 hover 或 selected 时使用主色描边和轻微主色外环；页面级 Tab 不套用描边选中态。
- [ ] 中间数据区域所有卡片 / 面板 / 图表卡 / 表格容器 / 链路节点 / 占位卡使用统一轻量 hover：主色浅描边、轻阴影、`translateY(-1px)`、`.14s` 过渡；AI 面板、按钮、Tab、表格行和输入框未误套用该效果。
- [ ] 联动筛选型指标卡（如 `认证方式分布`）有 hover、focus、selected、清除状态，使用 `aria-pressed`，点击后下方列表/表格确实同步变化，并在列表标题行显示当前筛选条件。
- [ ] 当前强制浅色状态下，筛选 chip / 时间范围 / 分段按钮的选中、未选中和禁用态对比清晰；未来明确恢复深色时再执行深色专项验收。
- [ ] 页面顶部筛选按钮、时间范围、上传/刷新/下载等操作保持单行，不出现按钮文字换行；自定义日期范围使用浮层或等价不挤压布局的方案。
- [ ] 日期时间输入和下拉选择器使用默认 36px 高度、`--radius-md`（8px）圆角、白底细边框和主色 focus 外环，没有内外双重重边框。
- [ ] `AI 解读` / `问 AI` 按钮带小 icon 和主色浅渐变重点样式，不与普通次级按钮混同。
- [ ] 图标按钮 tooltip 在顶栏、AI 面板头部、输入区、抽屉内均可见，不被 overflow 或边界裁切。
- [ ] 下拉菜单、日期时间选择器、筛选 Popover 的圆角、边框、阴影、hover 和选中态符合组件规范。
- [ ] 新增功能按钮没有使用 emoji 前缀；导入、导出、新建、删除、返回等常规操作使用标准按钮文案或统一线性图标。

- [ ] Skill Hub 的技能包启停、批量申请、业务审批人和应用测试入口符合本地 token、当前浅色主题和紧凑控件规范。
