# 图标规范

## 1. 图标原则

- 图标服务于识别和效率，不作为装饰堆叠。
- 同一页面不要混用多套图标风格。
- 后台界面优先使用线性图标，风格轻量、克制。
- 仅图标按钮必须提供 Tooltip 或可访问标签。
- Tooltip 浮层必须在真实页面布局中完整可见，不被 overflow 容器、顶栏、AI 面板、抽屉、输入区或页面边界裁切。

## 2. 尺寸

| Token | 值 | 用途 |
|---|---|---|
| `--icon-sm` | `16px` | 表格行操作、辅助图标 |
| `--icon-md` | `18px` | 默认工具栏、输入框图标 |
| `--icon-lg` | `20px` | 页面主操作、空状态辅助 |

实现要求：
- 图标容器和图标本身都必须固定宽高，`flex-shrink: 0`。
- SVG、图片 Logo、头像、图表 canvas 必须保持比例，不允许横向或纵向拉伸。
- 仅图标按钮使用正方形尺寸；按钮内 SVG 默认 `14-16px`，居中显示。
- 图标与文字的间距固定为 6~8px；不要靠字符空格控制间距。
- 页面标题、模块标题、表格操作、AI 助手工具按钮必须使用同一套线性图标语气，不混用 emoji、彩色插画和多套图标库。
- 仅图标按钮的 tooltip 方向按位置处理：顶栏/面板头部向下，底部输入区/页脚向上，避免超出视口或被裁切。
- 侧栏目录 chevron 必须是线性图标，收起向右、展开向下；不使用位图箭头或文本符号替代。

## 3. 颜色

- 默认图标：`--color-text-secondary`。
- 弱图标：`--color-text-tertiary`。
- 禁用图标：`--color-text-disabled`。
- 强调图标：`--color-primary`。
- 危险图标：`--color-danger`。
- 状态图标：跟随 success / warning / danger / info 语义色。

## 4. 常用图标场景

| 场景 | 建议 |
|---|---|
| 搜索框 | 左侧搜索图标，颜色 tertiary |
| 表格操作 | 查看、编辑、复制、更多、删除；危险操作用 danger |
| 状态标签 | 同色小圆点优先，不强制图标 |
| 空状态 | 可使用简单线性插画或图标，不做情绪化大插画 |
| Tooltip | 信息图标使用 secondary，悬停展示说明 |
| 模块标题 | 小型线性图标 + 主色浅底容器，尺寸稳定，不使用 emoji 前缀 |
| AI 助手 | 使用与后台一致的线性工具图标，可用主色点缀但不另起一套视觉语言 |
| AI 输入区 | 附件、发送使用 icon-only 方形按钮；熟悉图标不再额外放文字标签 |
| 刷新 / 后续若恢复亮暗切换 | 使用统一线性 icon-only 方形按钮 + tooltip，不用纯文字按钮；亮暗切换入口本期隐藏 |
| 技能包管理 | 每个技能包按语义使用不同线性 SVG 图标，但容器、线宽、尺寸、颜色保持一致；不要所有技能重复同一个 icon |

## 5. 缺口登记

本 Skill 不重复打包整套项目图标文件。使用顺序固定为：当前项目已确认 SVG / 组件、Figma 项目 icon 库、经确认后补充的新 SVG。

当确实存在缺口时：

1. 先确认图标语义、所属分类和使用场景，不臆断归类。
2. 检查当前项目与 Figma icon 库是否已有同义图标或状态变体。
3. 只有确认不存在时才新增，并同步默认、hover、active、disabled 等所需状态。
4. 在 `asset-inventory.md` 登记来源、命名、尺寸、线宽和使用位置。

不得直接引入 IconPark、Lucide 或其他外部库的默认图标来绕过项目图标库。
