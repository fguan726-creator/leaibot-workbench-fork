# 表格与列表专项规范

表格是当前乐享 AI 工作台最高频组件。职场员工审核、留言工单、线索池、员工管理、来源明细等列表页都优先套本规范。

内容槽中的表格结构、状态、响应式和交互边界同时遵守 `content-slot-design-contract.md`；本文件提供表格专项细节。

## 目录

1. 基础结构与列类型
2. 工具栏与批量选择
3. 分页与表格状态
4. 复杂能力、横向空间和固定列

## 1. 基础结构

- 表头：`--color-bg-muted` 背景，`--text-xs`，`--fw-medium`。
- 行高：普通业务列表默认 `--row-height-default: 48px`；明确的高密度单行表可选 compact `40px`。
- 单元格内边距：纵向 `--space-2`，横向 `--space-3`。
- 行分割线：`--color-border-subtle`。
- 行 hover：`--color-bg-subtle`。
- 选中行：`--color-primary-subtle`。
- 斑马纹可选：偶数行 `--color-bg-subtle`。

### 1.1 行高变体

| 变体 | 高度 | 适用场景 |
|---|---:|---|
| compact | `40px` | 单行、高密度任务或配置表 |
| default | `48px` | 普通业务列表默认值 |
| comfy | `56px` | 含头像、标签组合或辅助信息 |
| two-line | `64px` | 明确的主副两行内容 |

同一张表只能使用一种行高变体，不因单条数据内容多少在行间随机跳变。字段溢出应按语义选择省略、Tooltip、设计换行、展开行或详情页。

## 2. 列类型

| 列类型 | 对齐 | 字体 | 规则 |
|---|---|---|---|
| 名称 / 标题 | 左对齐 | 正文字体 | 可带副标题或描述 |
| ID / Key / Hash | 左对齐 | 等宽 | 中间省略 + 复制 |
| 数字 / 调用量 / Token | 右对齐 | 等宽 | 千分位显示 |
| 状态 | 左对齐 | 正文字体 | 使用状态标签 |
| 时间 | 左对齐 | 正文字体 | 列表可用相对时间，详情用完整时间 |
| 操作 | 右对齐 | 正文字体 | 固定最右，图标按钮 + Tooltip 或更多菜单 |

实现约束：

- 主副两行单元格必须给副文本使用专用 class，不使用 `td span`、`td div` 等宽泛元素选择器。
- 状态标签必须保持 `inline-flex` 和内容自适应宽度，不继承普通副文本的 `display:block`、外边距或整列宽度。
- 同一单元格同时包含副文本、状态标签、图标或操作时，分别使用语义 class，避免一种规则覆盖另一种组件。

## 3. 表格工具栏

推荐顺序：

1. FilterBar 左侧：搜索、筛选器、日期范围、状态条件和查询/重置。
2. TableToolbar 左侧：总量、当前视图或选中数量。
3. TableToolbar 右侧：刷新、导出、列设置、主操作。
4. 高级筛选：折叠，不默认占用多行；收起后仍显示隐藏条件数量或摘要。

筛选区和表格工具栏是两个语义层，不把所有控件塞进一行。紧凑筛选/工具栏控件统一 `28px`；普通表单控件使用 `36px`。

## 4. 批量选择

启用批量选择时：

- 行首显示复选框。
- 选中后出现批量操作条。
- 批量危险操作必须二次确认。
- 批量操作完成后给 Toast 反馈。
- 必须定义翻页、重新查询、切换 tab 后选择是否保留；默认重新查询和切换业务范围时清空选择。
- 批量操作展示对象数量和影响范围；部分成功时提供失败明细与仅重试失败项的入口。

## 5. 分页

- 分页器放表格底部右侧。
- 支持每页条数切换。
- 数据量少时可隐藏分页，但保持底部留白一致。
- 查询、排序、切换 tab 后通常回到第 1 页；刷新当前页尽量保留位置。
- 删除最后一页最后一项后回到最近的有效页。

## 6. 表格状态

| 状态 | 规则 |
|---|---|
| 加载中 | 骨架屏优先，避免大转圈 |
| 空数据 | 使用 Empty 结构，说明原因 + 引导操作 |
| 错误 | 显示错误说明 + 重试按钮，技术详情可折叠 |
| 无权限 | 说明权限不足，并给申请权限 / 联系管理员入口 |
| 部分失败 | 使用 Alert Banner 说明失败项，可查看详情 |

## 7. 复杂表格功能

以下能力按需开启，不要默认全开：

- 列排序
- 列筛选
- 全局搜索
- 批量选择
- 列显隐
- 拖拽排序
- 行展开
- 密度切换
- 固定列

默认推荐：搜索 + 状态筛选 + 分页 + 操作列固定。

## 8. 横向空间与固定列

- 表格根容器可横向滚动，页面根节点不得因此横向滚动。
- 操作列固定在最右侧并提供轻分隔；固定层不得遮挡相邻内容。
- 名称/标题列优先获得弹性宽度；数字、状态、时间和操作按内容设置合理最小宽度。
- 所有列都必须考虑长中文、长英文、ID、空值和未知状态。
- 右侧 Agent 打开、左侧导航展开/收起或容器 resize 后，表头与表体保持对齐。
