# 决策状态与剩余缺口

本文件只登记尚未闭环的项目级决策。已经明确的事项不得再次作为开放问题，也不得由单个页面自行改写。发生冲突时，以根目录 `SKILL.md`、`content-slot-design-contract.md` 和当前 0825 Vue 项目为准；0729 仅作历史非回归对照。

## 1. 当前已确定

### 品牌、色彩与字体

- UI 主色为 `#3370FF`；Lenovo 红只用于 Logo、危险状态和严重告警。
- success / warning / danger / info 使用 `design-tokens.md` 的当前语义色。在品牌团队正式调整前，不另造一套颜色。
- 标题与正文使用 `Source Han Sans CN`、`PingFang SC`、`Microsoft YaHei`、system-ui 回退栈；不引入 Inter 或 Chiron Hei HK。
- 技术内容使用 `JetBrains Mono`（可用时）、`SF Mono`、系统等宽回退；不得因首选字体缺失破坏布局。

### 壳层与主题

- 侧栏为 `168px / 58px`，顶栏为 `56px`，右侧 Agent 默认 `380px`、最大约 `492px`。
- 当前发布只呈现浅色主题：隐藏亮/暗切换入口，启动时强制浅色并忽略历史深色偏好。
- 深色 token 与运行时代码只作为未来能力保留，不属于当前页面设计和验收范围。只有用户明确恢复深色模式时才启用专项验收。

### 图标与插画

- 图标来源优先级为：当前项目已确认 SVG / 组件 → Figma 项目 icon 库 → 经确认后补充的新 SVG。
- 不得为了单页便利另行引入 IconPark、Lucide 等外部图标默认风格，也不得混用 emoji、文本符号和多套线性图标。
- 空状态默认使用项目现有线性图标或简洁线性占位，不新增情绪化大插画。
- 助手与产品头像复用当前项目资产；缺失资产时使用中性占位并登记，不临时生成新品牌形象。

### 表格能力

- 普通列表默认提供必要搜索/状态筛选、分页和最右操作列；具体以业务任务为准。
- 排序、列筛选、批量选择、列显隐、密度切换、拖拽排序、行展开和固定列均为按需能力，不全站默认开启。
- 只有数据对象、风险、规模和操作流程需要时才开启对应能力，并补齐加载、空、错误、无权限和批量结果状态。

### 间距

- 内容槽页面内边距为 `20px 24px`。
- PageHeader 到第一个业务区块在所有页型中统一为 `16px`，只允许由 PageHeader margin 或父容器 gap 其中一种机制产生。
- 其余顶层业务区块默认间距 `24px`，同一区块内模块默认 `16px`，普通卡片内边距默认 `20px`。
- KPI 组合统一为：页头到 KPI `16px`、KPI 卡间 `14px`、KPI 到下一模块 `16px`。

## 2. 仍需后续闭环

- 字体文件的授权、WebFont 打包方式和生产环境分发策略仍需工程/品牌确认；确认前继续使用当前回退栈。
- 当需求需要的语义图标在当前项目和 Figma icon 库中均不存在时，先向用户确认分类与语义，再新增并登记。
- 深色主题只有在未来明确恢复时，才需要重新验收 Logo、图表色、弹层、表格和内容槽页面。
- 语义色若未来获得品牌团队正式调整，以一次受控 token 变更处理，并完成全项目回归，不允许页面级零散覆盖。
