# PRD 生成页面验收清单

本清单用于 PM PRD、对话需求或文档需求生成页面后的最终检查。

## 需求覆盖

- 是否提取了业务目标、用户角色、主流程和数据对象。
- 是否覆盖 PRD 中的主操作、次操作、状态和权限。
- 是否补齐空、加载、错误、无权限、校验失败、保存中、保存失败、成功反馈。
- 是否处理批量操作、危险操作、状态变更和审批确认。
- 是否使用真实感中文业务文案，而不是 Lorem ipsum 或泛化占位。

## 项目一致性

- 是否先查找并复用了原项目相似页面或组件。
- 是否保持三栏工作台、顶部栏、中间内容槽和右侧 AI 助手规则。
- 是否使用现有 token、CSS 变量、class、组件密度和交互状态。
- 是否避免 Ant Design、shadcn 或通用后台默认视觉。
- 是否避免营销页、超大 Hero、装饰性渐变、卡片堆叠和页面孤岛。

## UI 契约

- 页面类型是否明确。
- 筛选、表格、详情、表单、弹窗、抽屉、Tabs、图表的选择是否符合 PRD。
- 主操作是否位于项目惯用位置。
- 危险操作是否有确认和可恢复提示。
- 长篇 AI 内容是否从右侧 AI 面板展开到中间内容槽，而不是挤在面板内。
- 是否提交页面区块图与相邻间距表；PageHeader、Summary、FilterBar、Tabs/Toolbar、Table、Pagination 的实测距离是否符合内容槽间距矩阵。
- 带 KPI 的列表页是否复用 `SummaryList`/`ListWorkspace`；同一数据集的 Tabs/Toolbar、Table、Pagination 是否保持同一 ListSurface，而不是被画布色空带拆散。

## 新增交互共用性

- 是否只有在既有交互不足时才新增交互。
- 是否说明了既有模式为什么不适用。
- 新交互是否能解决一类相似问题。
- 新交互是否可以命名、抽象、复用和沉淀。
- 新交互是否仍遵守项目 token、尺寸、状态、动效和当前强制浅色主题；是否避免阻断未来主题 token。

## 交付质量

- 文本是否不溢出、不遮挡、不换行破坏按钮。
- 表格列、筛选项、操作按钮是否在 1280px 以上可用。
- hover、active、disabled、loading、focus、error 状态是否完整。
- 当前页面是否保持强制浅色且没有历史深色状态残留；只有明确恢复深色模式时才检查深色主题完整性。
- 页面是否能直接在项目预览入口或目标工程中运行。
- 1280px 与常用大屏下均不存在未解释的 `>24px` 相邻空带、低于 token 的塌陷间距、margin+gap 叠加，或标准列表组件被固定高度拉伸到视口底部。
