# UI 文案与数据呈现规范

本文件只规定界面呈现文字，不替代完整产品文案策略。

## 1. Placeholder

- Placeholder 给示例，不重复标签。
- 使用 `--color-text-tertiary`。
- 搜索框示例：`搜索模型名称或 ID`。
- 输入框示例：`请输入数据集名称`。

## 2. Helper 帮助文字

- 放在复杂字段下方。
- 使用 `--text-xs` + `--color-text-secondary`。
- 说明字段用途、格式或影响范围。

## 3. 错误文字

- 放在出错控件下方。
- 使用 `--text-xs` + `--color-danger`。
- 说明“怎么改”，不要只说“不合法”。

示例：

- 不推荐：`输入错误`
- 推荐：`请输入 6–32 位字符，支持字母、数字和下划线。`

AI改图／AI插图的字段、对象、区域、步骤及任务级提示位置，以及技术故障、提示去重和恢复文案，统一读取 [AI商品管理反馈合同](ai-product-feedback-contract.md)。严重程度不决定显示位置。

## 4. 空状态

结构：图标 / 插画 + 一句说明 + 一个引导操作按钮。

示例：

- `还没有模型，点击「创建模型」开始。`
- `当前筛选条件下没有任务，尝试重置筛选。`

## 5. Toast

- 成功：说明结果，例如 `已复制 API Key`。
- 失败：说明失败原因和恢复动作，例如 `导出失败，请稍后重试`。
- 警告：说明影响范围，例如 `配额使用已超过 85%`。
- 信息：说明系统状态，例如 `任务已加入队列`。

## 6. 数据格式

| 类型 | 规则 | 示例 |
|---|---|---|
| ID / Key / Hash | 等宽字体 + 中间省略 + 可复制 | `sk-••••3a9f` |
| 大数字 | 千分位 | `1,280,500` |
| 日期时间 | 24 小时制 | `2026-06-03 14:30` |
| 相对时间 | 列表可用 | `3 分钟前` |
| 百分比 | 直接显示百分号 | `85%` |
| 时长 | 中文单位 | `12 分钟` |
| Token / 调用量 | 千分位 + 等宽 | `128,430` |

## 7. 中英文与术语

- 中英文之间留一个空格。
- 中文使用全角标点。
- 英文专有名词保持官方写法：GPU、API、JSON、Token、URL、ID。
- 按钮文案使用动词开头：创建、保存、导出、复制、重试、删除。
- 危险操作文案必须明确对象：`删除模型`、`停用 Key`。

## 8. 技术错误呈现

- 普通用户可见区域说明影响与恢复动作。
- 错误码、堆栈、接口响应放入“查看详情”折叠区。
- 不要把长堆栈直接顶在页面主区域。
