# 场景技能包规则标注与产品说明交付计划

**目标**：页面说明当前账号能否编辑及原因，并交付覆盖创建到管理全流程的对外产品介绍 Word。

**范围**：保留 9a929a25 权限、状态与四步流程；仅更新 Skill Hub 场景技能包列表/详情的规则标注及同一 POC 记录。文档与验证截图存放交付目录，不把临时工具、文档成品或依赖放进产品 Git。

## 实施

1. 基于最新服务器 main 与已发布 new 提交继续隔离开发，核对并行改动。
2. 在现有页面提供可展开的编辑规则，以及当前账号不可编辑的具体原因；待审区分可撤回本人内容和他人审核内容，已发布修订沿用原规则。
3. 从当前源码与真实 UI 核对产品事实，编写产品定位、四步创建、试运行、审核发布、编辑矩阵、依赖和版本管理、完整业务案例及常见问题。
4. 文档采用清晰产品语言与真实模拟页面截图，明确当前 POC 的演示边界，不写部署细节、开发代码或未经实现的能力。使用可编辑 Word，逐页渲染检查。
5. 完成修改页面的设计检查、规范、类型、构建和项目必需检查；浏览器仅验证本轮规则与文档相关路径，避免重复上一轮全链路。
6. 源码同步服务器预览分支；仅发布 new，保护正式环境、他人源码、现有资源与 admin-runtime；沿用同一日志记录实际发布元信息。
