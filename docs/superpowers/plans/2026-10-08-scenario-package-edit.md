# 场景技能包编辑状态与管理入口

用户要求：Skill Hub 中管理员和创建者可编辑场景技能包，编辑状态参考 Skill 管理。只在 new 预览验证，正式环境另行确认。

## 已确定范围

- 创建者具备创建及跨菜单编排权限时，可编辑自己的草稿、驳回、已发布与已禁用内容。
- 管理员可维护已发布、已禁用内容及其衍生的草稿、驳回修订，保证首次保存后仍可继续编辑。纯新建的他人草稿、驳回内容按当前 Skill 范围保留为只读。
- 待审核不得直接编辑；原创建者或本轮实际提交人可确认撤回，再继续编辑。其他管理员保持审批、驳回入口。
- 管理员编辑保留原 ownerId，保存/试运行/提审使用当前 actor，拒绝伪造 owner 和陈旧 baseUpdatedAt。
- 保存修订只递增一次版本，保留可信 publishedSnapshot 和 onlineStatus；重新审核前旧线上版本保持。
- 从可信记录累计本修订编辑者，独立审核排除原创建者、实际提交人及本修订编辑者。新增创建能力和 Skill 引用权限不自动扩大。
- 试运行从 store 获取可信原记录，不能通过界面传入的所有者或权限字段绕过检查。

## 实施和验证

1. 在真实 domain/store 测试中覆盖管理员编辑、保留归属、版本与线上快照、过期编辑、撤回及禁止自审；先观察旧实现失败。
2. 更新 domain、store、存储校验与试运行传递，保留默认新建调用的严格校验。
3. 列表和详情共用状态动作；编辑页面分离原创建者和当前操作账号，账号切换或失权锁定旧编辑会话；撤回复用现有确认对话框。
4. 真实 Vue 测试验证列表/直接路由、跨创建者保存、账号切换、撤回确认及重复操作。
5. 设计检查、类型、规范、构建、产品回归与局部浏览器检查通过后，仅发布 new；保护 admin-runtime、正式页面与其他人的源码。
6. 使用同一条 POC 日志记录实际 new 发布人、时间和版本，服务器 Git 保存独立预览分支。
