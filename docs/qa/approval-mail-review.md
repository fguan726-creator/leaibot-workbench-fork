## 演示步骤

1. 打开权限管理 → 审批列表，在一条直线经理待办中点击「审批」→「审批邮件演示」。也可在提交申请后的提示弹窗打开邮件演示。
2. 模拟收件箱选择当前审批节点的「申请人直线经理」「被申请人直线经理」或「业务负责人」邮件。
3. 选择「有账号审批」进入原系统内审批；选择「无账号审批」打开不使用登录态的独立页。两种方式操作同一张申请，不能重复处理同一节点。
4. 可同时打开两个入口，任一页面提交后，另一页面更新为只读/最新节点。刷新或重开原邮件能继续查看进度。
5. 数据保存在浏览器本地，请用生成邮件的同一浏览器、同一站点，不要用无痕窗口或另一台电脑打开。无账号的含义是不要求工作台账号，不是跨浏览器同步。
6. 需要重演时使用另一张待审批申请或重新提交一张申请，不回滚已审批记录。
7. 独立审批演示使用本机 localhost/127.0.0.1 或 HTTPS 的现代浏览器，依赖 Web Locks 做同站点多页面提交互斥。旧浏览器/非安全 HTTP 环境保留原有系统内审批，不提供新的独立审批入口。

## 可重复验证

- 单元：支持原生 TypeScript 的 Node 执行 `node --test scripts/approval-mail-review.test.mjs`。
- 浏览器：在 vue-app 下设置 `PERMISSION_QA_BASE_URL` 指向 preview 服务，执行 `node scripts/verify-approval-mail-review-browser.mjs`。使用隔离浏览器上下文，不改用户演示数据；截图在系统临时目录 `approval-mail-review-qa`。
- 工程：类型、lint、设计守卫、相关权限/登录回归、隔离目录构建、shell smoke。构建禁止覆盖 public/admin-vue。
- 正式模式隔离可复验：先构建 server 认证模式并启动隔离 preview，再设置 `APPROVAL_SERVER_QA_BASE_URL` 后执行同一浏览器脚本。即使注入一条有效的 POC 本地记录，也不得展示申请内容或允许审批。
