# Skill Hub 状态与技能包应用测试

基线：`bd79a8f6601473b56707bdfb11056cae913cc3c0`。

用户要求去掉 Skill Hub 中的降级运行。本轮先在 NEW 提供取消机制的预览：任一声明依赖不可用时暂停；实际激活节点缺权限或确认、审批证据时，整个运行在开始前阻断。未满足条件的分支正常不执行，保持原有语义。

## 范围

- 移除场景包降级状态的统计卡、筛选项及标签，详情改为依赖状态说明。
- 健康状态与运行校验统一取消异常节点跳过后继续运行的路径；创建提交页同步文案。
- 保留存量数据读取兼容、包 ID、用户内容、版本、审核历史、已审核快照与禁用状态，读取时重算派生健康状态。
- 保留工作流统一执行要求与返回编排自动重试、其他 Skill 状态、权限与菜单。
- 仅发布 NEW；正式环境保持现有版本。

## 技能包应用测试

- 列表及详情增加“应用”，直接打开 AI 助手，不修改输入框中未发送的内容。
- 已发布且依赖可用的技能包可以应用；待升级仍按已审核固定版本运行样例。有旧审核快照的草稿、待审核或已驳回修订继续使用旧快照；没有已审核版本、已禁用或依赖暂停时不可应用，并显示原因。
- 同时校验使用技能包、实际激活节点的菜单、技能、数据范围及操作权限。全局确认在 AI 助手中单独请求，不借用作者的试运行确认，也不伪造历史节点审批。
- 确认只对当前账号、会话、固定版本与范围有效，15 分钟后失效；取消、新会话、恢复历史、新提问或权限变化会使旧确认失效。入口及确认读取最新持久化状态，其他标签页禁用或更换版本后需重新发起。
- 仅进行本地 POC 样例展示，不调用真实 Skill、聊天或业务接口。优先使用固定版本一致的已审核成功样例；没有时使用该精确版本的本地样例，并注明来源。缺少精确样例时显示未完成，后续节点不再展示成功。没有命中条件的可选分支正常跳过。
- 不影响普通 Skill 评估、场景包编排、现有管理按钮、菜单和权限配置。

## 验证与交付

针对不可用依赖、激活可选节点缺权限/证据、未激活分支、旧降级记录和快照增加回归。补充应用状态、固定版本、权限、整体确认、跨标签状态变化、确认过期与重放、历史会话和输入保留回归。执行场景包回归、类型检查、lint、设计检查、构建和壳层检查；本地浏览器验证列表、筛选、详情与 AI 应用测试，明确使用模拟登录和本地样例。通过 Git 正常合并源码，验证 NEW 资源与发布台账，保护共享运行文件。完成后核实远端已保留代码，再正常移除本任务临时 worktree。
