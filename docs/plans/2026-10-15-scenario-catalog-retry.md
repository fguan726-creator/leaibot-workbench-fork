- 仅增加该 Skill 的 `v1.0.0` 明示本地模拟输入输出；不查真实数据、不改线上 Skill 版本。
- 保留第一轮第二节点反馈不完整的 POC 演示，直接重试以及返回编排后下一步均重新生成完整样例反馈。
- 保留所有未知版本、未知 Skill、权限、依赖、工作流确认及审批拦截；不把预期输出冒充本轮输出，不让失败结果通过提交审核。
- 保留 1015 样式、全局执行要求、草稿/待审核应用、个人赞踩、菜单及账号权限功能。
- 本轮更新 NEW，环境发布时间、执行人和版本通过现有发布台账记录。

## 验证与交付

1. 用真实默认目录建立红色回归；检查全部默认已发布可选演示 Skill 的版本样例覆盖。
2. 验证两节点首轮反馈、重试、上下游传递和提交审核门禁，并检查负向边界。
3. 浏览器使用可见目录选择同一组合，分别验证直接重试和返回编排后下一步；确认第一步整体执行要求仍有效。
4. 完成场景、权限及反馈专项回归、类型检查、lint、设计检查、构建及壳层检查。
5. 在隔离工作区构建，通过 Git 保存源码，更新 NEW；保护正式产物及共享运行文件。
6. 保存外部验证证据，停止临时服务并按协作规则清理本任务临时工作区。
