## 4. 当前验收结论

### SPEC-13 普通授权三级树（2026-09-08）

- P13-01：所有普通授权入口均为目录 → 数据源 → 授权项；前两层只展开，叶子才可勾选。
- P13-02：四个业务目录、五个二级数据源与数据源管理一致；已有叶子 ID 保持不变，角色范围不扩大。
- P13-03：展开/收起、搜索源名与叶子名、清空/关闭搜索不丢选择；搜索保留父级路径，各目录互不影响，支持局部空态。
- P13-04：首次申请、系统内申请、角色详情、用户继承及复制来源保持可编辑/只读边界；自定义授权不变。
- P13-05：数据源改名、移动与删除同步其全部叶子；新增数据源按现有 POC 逻辑生成范围值。
- P13-06：1440×900、1280×800、首次访问窄屏无横向溢出，展开按钮支持键盘，目录搜索自动聚焦。
- 状态：P13-01 至 P13-06 本轮通过。设计守卫、Lint、TypeScript、权限范围、用户管理、自定义授权、角色冲突、15 项产品契约均通过；隔离生产构建与该产物的 shell smoke 通过。
- 浏览器证据：权限范围全流程、用户管理、自定义授权原回归与新增 `pnpm test:permission-data-tree:browser` 均通过。覆盖 1440×900、1280×800、首次访问 390×844、审批嵌套弹窗和 Agent 展开态。
- 新增数据源联动专项验证初始 4 个目录/5 个数据源/14 个授权项、角色原有两项授权回显、改名/移动后叶子与勾选不变、删除清理全部叶子、新增不自动授予普通角色。桌面弹窗和页面横向溢出均为 0，浏览器无 pageerror 或新增 console error。
- 截图证据位于运行机器临时目录：`leaibot-data-tree-role-1440.png`、`leaibot-data-tree-role-1280.png`、`leaibot-data-tree-source-moved-1280.png`；已查看 1280 角色编辑截图，确认三级缩进、展开标识、叶子复选框和固定底部操作。
- 隔离构建使用 `pnpm exec vite build --outDir <全新临时目录> --emptyOutDir`；使用 `PORTAL_SMOKE_OUT_DIR=<同一目录>` 执行 `pnpm smoke:shell`。未覆盖仓库的 `public/admin-vue` 或 `admin-runtime`。
- 范围限制：本轮为本地 mock POC 验收，未进行后端联调或线上发布。本地既有 `/api/admin/me` 探测 500 后进入 preview，构建仍有现有 Sass legacy API 与大 chunk 提示；未把这些既有问题标为本次已修复。

### SPEC-14 固定业务负责人单选（2026-09-08）

- P14-01：首次申请、创建账号、权限变更和用户管理提单均须选择一位固定候选人；两个分组、五个选项，默认空值，不允许自由输入或多选。
- P14-02：未选/非法值不能提交，修改选择只保留最后一位；新增/复制角色或仅选择数据权限均不改变指定人。
- P14-03：审批预览、详情、通知和实际流转使用同一快照；经理修改权限不会重新按角色分配；只有指定人审批通过才整体生效。
- P14-04：用户基本资料直接保存、启停与重置密码不受影响；旧申请保留原多人审批，三级树和自定义授权回归不变。
- 验证结果（2026-09-08）：固定负责人单元测试、申请信息 Schema、权限快照、用户管理、自定义二维表、角色冲突及 15 项产品契约测试通过；设计规范守卫、TypeScript、ESLint、隔离 Vite 构建和 Shell 冒烟通过。
- 浏览器实测通过：权限全流程、用户管理、自定义授权及三级树回归；新增 test:business-approver:browser 覆盖必填/换选、两组五人单选、仅数据权限实际审批、经理新增多个角色后指定人不变、业务组织必填和唯一负责人通过后整单完成。
- 视觉与布局：1440×900、1280×800、390×844 验证无页面横向溢出。首次访问页限定路由的最小宽度例外已修正，系统内桌面布局不变；复用现有表单视觉和局部字段组件。
- 环境边界：本地 POC 预览的 /api/admin/me 返回 500，使用已有预览身份回退；本轮未验证真实后端认证、邮件发送或生产授权执行。未提交、未推送、未部署，构建只输出临时目录。

### 二级数据源搜索（2026-09-09）

- 每个二级数据源的授权数量右侧增加搜索图标，复用一级搜索样式；只筛选本数据源的授权项，其他数据源不受影响。
